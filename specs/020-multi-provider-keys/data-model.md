# Data Model: Choice of AI Provider and Bring-Your-Own Key

## Migration 0018 (Postgres, `grounnel` schema)

Needs sign-off before it is applied to the shared database.

| Table | Column | Type | Default | Meaning |
|---|---|---|---|---|
| `grounnel_runs` | `provider` | text: `gemini` \| `deepseek` \| `qwen` | `'gemini'` | provider that judged this run |
| `grounnel_runs` | `model` | text, nullable | null | exact model name; null only on rows written before this column |
| `grounnel_runs` | `key_source` | text: `site` \| `own` | `'site'` | whose account paid for judging calls |

Do not add `provider` or `model` to `grounnel_llm_calls`. Both columns already exist, `notNull`,
created in `0011_swift_spiral.sql`, and written on every call from `this.provider.mode` and the
model string. An `ALTER` that adds them fails with "column already exists" and leaves the three
run columns unapplied. New writes still set the call's `model` to the model actually invoked.

`key_source` is read by `scripts/compare-providers.ts` when it prices a run. It is not selected
into the status or share payload.

Defaults make every existing run read as Gemini on the site's key, which is true. `model` stays
null on those rows rather than inventing a name. There is no column for the key, and no column
derived from it (no hash, no prefix).

Judging cost joins `grounnel_llm_calls.run_id` to `grounnel_runs.provider` and excludes
`stage = 'discovery'`. Discovery rows are inserted with `provider` hardcoded to `gemini` for every
run, so grouping the call table by its own `provider` column mixes search spend into Gemini and
drops it from Qwen and DeepSeek.

`gateOverrides` counts rows in `grounnel_gate_events` where `overridden` is true, grouped by
`gate`, for that provider's comparison runs. `searchCostPerRunUsd` is the site Gemini discovery
spend and is not included in `judgingCostPerRunUsd`. `judgingCostIsUpperBound` is true when a
DeepSeek run had no cache-token split and was priced entirely at the uncached input rate.

Generated by `scripts/compare-providers.ts`, which scores with `evaluateGrounnelRun`. Never edited
by hand. Run it with `tsx` from `scripts/`. It is not a `dist/` build output.
