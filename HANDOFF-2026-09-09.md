## Live bugs, found and NOT fixed

Both in `biassemble/frontend/src/components/grounnel/HighlightedArticle.tsx`, both visible on every
result today. Introduced by the T23 verdict-gating change (commit `48f8349`).

1. **`sourcesUncited` includes `'contradicted'`** (~line 126), and its render branch (~line 219)
   emits *"Supporting sources (no exact sentence matched):"*. A refuted claim shows its **refuting**
   evidence labelled as supporting it. Directly contradicts the philosophy the About page will
   state. Fix: `contradicted` gets its own flag rendering **"Refuting sources"**.
2. **`verdict === null` falls through all four explanatory flags** (~line 120), so a claim whose
   verification failed after retrieval renders bare source links. Fix: a branch on `verdict === null`
   — not on `sources.length > 0` as a proxy — rendering **"Verification incomplete — sources
   retrieved but not evaluated"**. (`excluded` is fine; `notChecked` covers it.)

Tracked as T014/T015 in `biassemble/specs/004-grounnel-public-site/tasks.md`.

## Sessions are not persisted at all

`runId`, `articleText` and `sessionId` live only in React `useState`. No `localStorage`, no
`sessionStorage`, no cookie. A refresh, a new tab, or any nav click destroys a run that took ~200s.
Adding About/Stats to the nav makes this worse. Tracked as T018–T022.

## Reverted or refuted this session — do not re-propose

- **Two Vercel deploys for the two brands.** The Inngest app id is hardcoded `"biassemble"`, so two
  full-stack deploys collide on sync. (The CORS argument against it was *wrong* — frontend and
  backend are already separate cross-origin projects.)
- **`MAX_CLAIMS = 40`.** Truncates the 44/47-claim detection fixture, and claim count does not
  predict wall clock — a **4-claim run took 286s** while 44-claim runs average 215s.
- **Publishing "0 false accusations".** One was observed 2026-09-08 in run `2a701ffa`.
- **A subagent's claim that the SCA evidence was fabricated.** It searched `grounnel_llm_calls`; the
  text is in `grounnel_claims.evidence`. Verified present. Entity-collision findings stand.

## Working rules

- Never commit or deploy without being asked in that turn. Commit messages are ONE line,
  `feat|fix|chore|docs(T0XX): <desc>`, **no AI attribution ever**.
- Evals run deployed via Inngest only (Gemini geo-blocked locally). Budget: one case at
  `--repeats 5`. Full golden set only on explicit ask.
- Judge on false-accusation count, not aggregate accuracy.
- Code comments max 2 lines / ~200 chars; rationale goes in the spec or ADR.
- Don't ask when a deploy landed — poll it, then PUT the Inngest sync.
- Vercel CLI hangs here; use the REST API with the token from `~/.local/share/com.vercel.cli`.
- `.specify/memory/constitution.md` is an **unfilled template** in both repos — every speckit
  constitution gate is currently checking nothing. Governing rules are CLAUDE.md and AGENTS.md.
